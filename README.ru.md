# Todo - Модуль управления задачами

![Todo Icon](static/Todo.png)

Система управления задачами для создания, организации и отслеживания задач и дел.

## Описание

Модуль `Todo` предоставляет систему управления задачами для платформы osysHome. Он позволяет создавать задачи, устанавливать приоритеты, отслеживать статус выполнения и организовывать задачи.

## Основные возможности

- ✅ **Создание задач**: Создание и управление задачами
- ✅ **Организация задач**: Организация задач по категориям
- ✅ **Управление приоритетами**: Установка приоритетов задач
- ✅ **Отслеживание статуса**: Отслеживание статуса выполнения задач
- ✅ **Интеграция поиска**: Поиск задач по заголовку или заметкам
- ✅ **Поддержка виджетов**: Виджет панели управления со статистикой задач
- ✅ **Поддержка страниц**: Отдельная страница управления задачами

## Панель администратора

Модуль предоставляет административный интерфейс для:
- Просмотра задач
- Создания и редактирования задач
- Управления статусом задач
- Организации задач

## API

Модуль предоставляет RESTful API endpoints:
- **GET /api/Todo/...**: API управления задачами

## Использование

### Создание задачи

1. Перейдите в модуль Todo
2. Нажмите "Add Task"
3. Введите детали задачи
4. Установите приоритет и статус
5. Сохраните задачу

## Технические детали

- **База данных**: Модели SQLAlchemy
- **API**: RESTful API endpoints
- **Поиск**: Поддержка полнотекстового поиска
