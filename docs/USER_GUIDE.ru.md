# Todo - Руководство пользователя

## 1. Назначение модуля

`Todo` предназначен для ведения списков задач, планирования дел по времени и работы с напоминаниями.

Модуль позволяет:

- создавать несколько списков задач;
- назначать задачам приоритет;
- планировать задачи по времени или на весь день;
- получать напоминания до начала задачи;
- настраивать повторяющиеся задачи по расписанию cron;
- отмечать задачи выполненными и снимать отметку при необходимости;
- запускать пользовательский Python-код при создании, завершении и других событиях (в настройках плагина).

## 2. Базовые сущности

### 2.1. Список задач

Список это контейнер задач (например: `Работа`, `Дом`, `Покупки`).

Для списка задаются:

- название;
- теги (опционально);
- порядок отображения.

### 2.2. Задача

Минимально задача содержит только название.

Дополнительно можно задать:

- описание (`notes`);
- теги;
- список (`list_id`);
- приоритет (`0..3`);
- дату/время начала (`started`);
- режим `all_day`;
- настройки напоминаний и повтора (`settings`);
- cron повтора (`settings.recurrence_cron`) — только для задач с датой начала.

## 3. Типичные сценарии работы

### 3.1. Быстрый старт

1. Создайте список.
2. Добавьте в него задачу.
3. Укажите время начала, если задача должна сработать по расписанию.
4. Включите напоминание.
5. После выполнения отметьте задачу завершенной.

### 3.2. Заметка без расписания

Если у задачи не задано `started`, она считается заметкой:

- не участвует в расписании;
- не создает планировщик событий;
- удобна для бэклога и идей.

### 3.3. Задача "на весь день"

При включенном `all_day` дата хранится в дневном формате:

- начало: `00:00:00`;
- завершение: `23:59:59`.

## 4. Приоритеты задач

Используются уровни:

- `0` - низкий;
- `1` - обычный;
- `2` - высокий;
- `3` - срочный.

Рекомендуется использовать `2` и `3` только для действительно важных задач, чтобы список оставался информативным.

## 5. Напоминания

Настройки напоминаний находятся в `settings` задачи.

Основные параметры:

- `reminder_enabled` - включить напоминание;
- `reminder_offset_minutes` - за сколько минут до начала напомнить.

Пример: при `started=10:00` и `reminder_offset_minutes=30` напоминание придет в `09:30`.

Напоминания и коды «начало / окончание» выполняются через модуль **Scheduler**. Должен быть включён и работать плагин Scheduler; в настройках Todo можно задать код по умолчанию, в карточке задачи — переопределения на вкладке «Настройки».

## 5.1. Повторяющиеся задачи

На вкладке **Основное** карточки задачи (при включённой дате начала) поле **Cron повтора**:

- пустое значение — обычная одноразовая задача;
- cron-строка формата `минута час день_месяца месяц день_недели`, например `0 9 * * 1` — каждый понедельник в 09:00.

При **отметке задачи выполненной**:

- текущая задача остаётся в списке как выполненная;
- автоматически создаётся **новая** задача с тем же текстом и настройками на **следующий** момент по cron (относительно момента завершения);
- длительность (интервал между началом и окончанием) сохраняется, если она была задана до завершения.

Если cron указан неверно, задача всё равно можно завершить, но следующая копия не создастся — проверьте выражение и логи `Todo`.

## 5.2. Код при завершении

В **Todo → Настройки → События** задаётся **Код при завершении** (`code_on_completed`). Он выполняется один раз в момент отметки задачи выполненной (до создания следующей копии при повторе).

В коде доступны переменные: `task`, `task_id`, `event`, `params`, `logger`.

## 6. Выполнение задач

### 6.1. Отметка выполнения

При переводе задачи в выполненную заполняются поля:

- `completed` - время фактического завершения;
- `finished` - время окончания (в текущей модели синхронизируется с `completed`).

### 6.2. Отмена выполнения

Повторное переключение статуса очищает `completed` и `finished` (новая копия по cron при этом **не** создаётся).

## 7. Рекомендации по организации

- используйте отдельные списки для разных контекстов (работа/дом/личное);
- задавайте теги по единому шаблону;
- для задач без четкого времени не задавайте `started`;
- регулярно закрывайте выполненные задачи, чтобы сохранить актуальность списка;
- для рутинных дел используйте cron повтора вместо ручного дублирования задач.

## 8. Частые проблемы

- **Напоминание не пришло**: проверьте `started`, `reminder_enabled`, смещение, что задан код напоминания (в задаче или в настройках плагина), что Scheduler активен и в его списке есть задачи `Todo.task.*`.
- **Ошибка при срабатывании напоминания**: убедитесь, что osysHome запущен; код хука не должен падать при выполнении (смотрите логи `Todo` / Scheduler).
- **После завершения не появилась следующая копия**: проверьте, что указана дата начала и непустой корректный `recurrence_cron`.
- Задача не отображается в выборке: проверьте фильтр по списку и статусу выполнения.
- Время выглядит неверно: проверьте часовой пояс сервера (cron и Scheduler ориентируются на него) и формат даты.
