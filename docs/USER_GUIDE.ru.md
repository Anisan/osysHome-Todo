# Todo - Руководство пользователя

## 1. Назначение модуля

`Todo` предназначен для ведения списков задач, планирования дел по времени и работы с напоминаниями.

Модуль позволяет:

- создавать несколько списков задач;
- назначать задачам приоритет;
- планировать задачи по времени или на весь день;
- получать напоминания до начала задачи;
- отмечать задачи выполненными и снимать отметку при необходимости.

## 2. Базовые сущности

### 2.1. Список задач

Список это контейнер задач (например: `Работа`, `Дом`, `Покупки`).

Для списка задаются:

- название;
- теги (опционально);
- порядок отображения.

### 2.2. Задача

Минимально задача содержит только название.

Дополнительно можно задать:

- описание (`notes`);
- теги;
- список (`list_id`);
- приоритет (`0..3`);
- дату/время начала (`started`);
- режим `all_day`;
- настройки напоминаний (`settings`).

## 3. Типичные сценарии работы

### 3.1. Быстрый старт

1. Создайте список.
2. Добавьте в него задачу.
3. Укажите время начала, если задача должна сработать по расписанию.
4. Включите напоминание.
5. После выполнения отметьте задачу завершенной.

### 3.2. Заметка без расписания

Если у задачи не задано `started`, она считается заметкой:

- не участвует в расписании;
- не создает планировщик событий;
- удобна для бэклога и идей.

### 3.3. Задача "на весь день"

При включенном `all_day` дата хранится в дневном формате:

- начало: `00:00:00`;
- завершение: `23:59:59`.

## 4. Приоритеты задач

Используются уровни:

- `0` - низкий;
- `1` - обычный;
- `2` - высокий;
- `3` - срочный.

Рекомендуется использовать `2` и `3` только для действительно важных задач, чтобы список оставался информативным.

## 5. Напоминания

Настройки напоминаний находятся в `settings` задачи.

Основные параметры:

- `reminder_enabled` - включить напоминание;
- `reminder_offset_minutes` - за сколько минут до начала напомнить.

Пример: при `started=10:00` и `reminder_offset_minutes=30` напоминание придет в `09:30`.

## 6. Выполнение задач

### 6.1. Отметка выполнения

При переводе задачи в выполненную заполняются поля:

- `completed` - время фактического завершения;
- `finished` - время окончания (в текущей модели синхронизируется с `completed`).

### 6.2. Отмена выполнения

Повторное переключение статуса очищает `completed` и `finished`.

## 7. Рекомендации по организации

- используйте отдельные списки для разных контекстов (работа/дом/личное);
- задавайте теги по единому шаблону;
- для задач без четкого времени не задавайте `started`;
- регулярно закрывайте выполненные задачи, чтобы сохранить актуальность списка.

## 8. Частые проблемы

- Напоминание не пришло: проверьте `started`, `reminder_enabled` и смещение.
- Задача не отображается в выборке: проверьте фильтр по списку и статусу выполнения.
- Время выглядит неверно: проверьте часовой пояс хоста и формат даты.
